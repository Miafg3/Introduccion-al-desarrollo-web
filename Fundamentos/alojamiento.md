# ¿Qué es el alojamiento web?

El **alojamiento web** es un servicio que permite almacenar los archivos de un sitio web en un **servidor** conectado a Internet para que cualquier persona pueda acceder a él en cualquier momento.

Un servicio de alojamiento web utiliza computadoras especiales llamadas **servidores**, las cuales:

- 🌍 Están conectadas a Internet.
- ⚡ Permanecen encendidas las 24 horas del día.
- 💾 Almacenan los archivos de tu sitio web.
- 🚀 Responden a las solicitudes de los usuarios cuando visitan tu página.

> 📌 En pocas palabras, el alojamiento web es el lugar donde "vive" tu sitio web.

---

## ¿Por qué es necesario el alojamiento web?

Podrías guardar tu sitio web en tu computadora, pero tendría varios problemas:

- Tu computadora puede apagarse.
- Puede quedarse sin Internet.
- Puede cambiar de dirección IP.
- No está diseñada para recibir miles de visitas.
- Si ocurre un corte de energía, tu sitio dejaría de funcionar.

En cambio, un servidor de alojamiento web ofrece:

- ✅ Disponibilidad las 24 horas del día.
- ✅ Conexión a Internet de alta velocidad.
- ✅ Copias de seguridad (Backups).
- ✅ Mayor seguridad.
- ✅ Certificados SSL.
- ✅ Soporte técnico.
- ✅ Mayor estabilidad.

> Por eso la mayoría de los sitios web viven en servidores y no en computadoras personales.

---

## Tipos de alojamiento web

### 1. Alojamiento compartido (Shared Hosting)

En este tipo de alojamiento varios sitios web utilizan el mismo servidor.

### Ventajas

- Fácil de usar.
- Ideal para principiantes (Blogs, Portafolios, Sitios personales, Pequeños negocios, etc.)

---

### 2. Alojamiento dedicado (Dedicated Hosting)

Todo el servidor pertenece a un solo cliente.

### Ventajas

- Máximo rendimiento.
- Mayor seguridad.
- Control total del servidor.
- Ideal para Grandes empresas y sitios con mucho tráfico.

---

### 3. Servidor privado virtual (VPS)

Un servidor físico se divide en varios servidores virtuales independientes. Cada usuario tiene recursos propios.

### Ventajas

- Mejor rendimiento que un hosting compartido.
- Más control.
- Más flexible.
- Ideal para tiendas en línea, proyectos medianos, aplicaciones web, etc.

---

### 4. Alojamiento en la nube (Cloud Hosting)

El sitio web se ejecuta utilizando varios servidores conectados entre sí. Si uno falla, otro continúa funcionando.

### Ventajas

- Alta disponibilidad.
- Muy escalable.
- Excelente rendimiento.
- Ideal para aplicaciones modernas, sitios con mucho tráfico, empresas en crecimiento, etc.
